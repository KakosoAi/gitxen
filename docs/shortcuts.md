# Keyboard shortcuts

Press **F1** in Gitxen for the list that matches your version.

| Shortcut | Action |
| --- | --- |
| Ctrl+O | Open a repository |
| Ctrl+K | Launcher: jump to a repository, branch or commit, or search commits in every repository |
| Ctrl+T | Go to (palette) |
| Ctrl+Shift+P | Command palette |
| Ctrl+R | Refresh |
| Ctrl+W / Ctrl+F4 | Close the current tab |
| Ctrl+Shift+1 | Simple mode |
| Ctrl+Shift+2 | Advanced mode |
| Ctrl+Shift+Z | Zen mode |
| Ctrl+Enter | Commit (in the message box) |
| Esc | Close the dialog or panel, back to Home |
| F1 | Show shortcuts |
| F12 | Git activity console |
