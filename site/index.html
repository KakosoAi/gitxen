A fast, honest git client for Windows.

Gitxen runs the git you already have and shows you every command it ran. Stage by hunk, rebase by dragging, find any commit in any repository. Free and open source under the GPL.

irm https://raw.githubusercontent.com/KakosoAi/gitxen/main/setup/gitxen/install.ps1 | iex

Per user, no admin rights needed. Checks the download against its published SHA-256.

Windows 10 (1809) or later, x64. Needs git installed.

  • A real terminal. PowerShell, cmd, Git Bash or WSL on a pseudoconsole, so prompts such as Oh My Posh, colours and full-screen programs all work.
  • Looks like Windows Terminal. Font, size, cursor and colour scheme are read from your Windows Terminal settings. One click opens the folder there instead.
  • gx on the command line. Repository stats, search across repositories, new repositories from a template, and a GitHub account per repository for push and pull.
  • Watch what Gitxen runs. Press F12 for every git command, its output and how long it took.

docs: how it behaves

The promises, written the way git stores settings.

gitxen.git=yoursRuns the git.exe you installed, as a separate program. Nothing is re-implemented, so the result is what git says.
gitxen.telemetry=noneNo usage data, no analytics, no account of its own.
gitxen.tokens=held-by-ghGitHub sign-in stays in the GitHub CLI. Gitxen asks it for a token per command and never stores one.
gitxen.ai=opt-inAI-written commit messages only if you add your own Anthropic key; it is kept in Windows Credential Manager.
gitxen.license=GPL-3.0-or-laterFree to use, study, change and share. A copy you distribute stays open too.
